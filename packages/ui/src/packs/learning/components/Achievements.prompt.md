## Purpose

See the learning badges you earned and how to unlock the rest.

## Pick

A grid of learning milestone badges with earned dates and unlock criteria. Not consecutive days of a habit (Streak), photos (Gallery) or redeemable rewards (Rewards).

## Writer

- Use earned for the date an earned badge was awarded. For locked badges leave earned null and put any unlock criterion in how.
- When asked for one badge per row, set arrange to "rows". Otherwise leave arrange null unless a layout is requested.
