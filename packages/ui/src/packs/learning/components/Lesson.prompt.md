## Purpose

Learn one idea from a short explanation and worked example before practising it.

## Pick

Teach one idea with a titled explanation, an optional illustrated example and a continue action. Not a short supporting sentence (Note), long-form reading (Article) or an assessed question (Quiz).

## Writer

- Put the explanation in text and the scenario in example. For any unrequested axis use null, not its default enum value.
- To hide a saved example, fill example and emit "detail":"brief". Unless explicitly requested, emit "emphasis":null.
- For a generated image, use `step_illustration` or `cover` in `photo`. Use only to illustrate a lesson or its main concept. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
