## Purpose

See a practice score and review the mistakes before trying again.

## Pick

A finished quiz or practice outcome: score, time, points, mistakes to review and a retry. Not independent summary numbers (Stats), a goal (Progress), confirmation (Success) or a sports score (Scoreboard).

## Writer

- Write right and of as counts, not a percentage. Do not write a wrong count or score label. Include only supplied mistakes, never more than of minus right.
- Leave emphasis null unless explicitly requested.
- Show supplied time and points by default with detail null. Use detail "brief" only if the person explicitly asks to hide time and points, and keep both values in their fields. Use null for missing figures.
