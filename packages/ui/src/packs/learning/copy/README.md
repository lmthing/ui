# Learning copy

Import through `index.ts`.

- `Achievements.ts`: badge details and read lines from validated data and the learning words.
- `Assignments.ts`: language-aware deadline and subject-mark helpers.
- `Flashcard.ts` formats the derived number of cards left using the pack's words.
- `Lesson.ts`: data-only reading helpers. Built-in words live in `../lang`.
- `Path.ts`: wording for unit controls and model readings, using the pack language.
- `Quiz.ts` and `quiz-answers.ts`: localized Quiz copy and pure answer helpers.
- `Timetable.ts`: localized reading text and timetable display helpers.
