## Purpose

View and manage one job interview already arranged for an applicant.

## Pick

One arranged hiring interview with interviewers, time, format, link and confirmation or cancellation. Not a day's agenda (Timeline), available times (Slots), or a service appointment (Appointment).

## Writer

- Use the agreed local date and 24-hour time, plus minutes; do not write a calculated end time or past flag. Link is optional and must use HTTPS.
- Use style "checklist" only for an explicitly requested prep guide; put the prep steps in prep, not in the interviewers or meeting details.
- Set rescheduleGoto only when the brief asks for a separate rescheduling link. Keep goto as the ordinary interview edit link.
