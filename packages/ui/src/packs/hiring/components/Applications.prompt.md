## Purpose

Track my job applications and log the follow-ups I owe.

## Pick

A job seeker's own applications to multiple employers with dated next actions, follow-up logging and application history. Not employers reviewing people (ApplicantPipeline), one flat list with a static badge and link per row (List), or a simple checklist (Checklist).

## Writer

- Leave applied absent for saved roles. Supply next when nextAt is present. Do not write calculated due notices, day counts, urgency or totals.
- For a request to show application cards, write surface "card" and density null. Only set density to "compact" when the user separately asks for tighter spacing; never write "comfortable" as a default.
