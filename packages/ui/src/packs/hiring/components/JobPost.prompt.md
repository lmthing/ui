## Purpose

Review employment terms and requirements before saving an opening or starting an application.

## Pick

For a tappable photo, role title and one-line teaser opening a separate details screen, choose Card, never JobPost. Choose JobPost only when the component itself displays employment terms such as a pay range, requirements or the application deadline. Terms the request says not to show do not qualify. Not several openings (List), a staff shift (OpenShift), or goods for sale (Product).

## Writer

- Pay is optional, numeric, and min must be at most max. Do not write currency or whether the opening is closed. Apply opens the form, not an outbound submission.
- For a normal job post write "detail":null,"density":null,"surface":null. If asked to hide the description, use "detail":"brief" and keep about in the record; still write "density":null,"surface":null unless those finishes are explicitly requested. Never write a default surface value in place of null.
