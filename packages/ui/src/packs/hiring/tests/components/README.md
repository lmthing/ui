# Hiring component tests

- `ApplicantPipeline.test.ts`: counted stages, terminal outcomes and active applicant moves.
- `Candidate.test.ts`: evidence review, actions, decisions and states.
- `Interview.test.ts`: meeting details, lifecycle gates and cancellation confirmation.
- `Applications.test.ts`: follow-up order, histories and withdrawal confirmation.
- `JobPost.test.ts`: opening details, pay, deadline and save/apply/publish actions.
- `JobFeed.test.ts`: open-role rows, bounds, states, bookmarks, and eligible apply actions.
- `ResumeProfile.test.ts`: résumé bounds, full and brief layouts, local controls and sharing.
- `Offer.test.ts` and `Offer.actions.test.ts`: employment terms, response expiry and confirmations.
