## Purpose

Log today's medicine doses by time, including taken, skipped and remaining pills.

## Pick

Medicines or supplements on schedule, with doses, taken/skipped marks and refill stock. Not ordinary jobs (Checklist) or nudging one count (Counter).

## Writer

- Write dose mark null unless explicitly requested. For a request to hide stock alone, only detail is set. To hide individual pill counts, set detail brief but keep left and refillAt in the data. Mark only an explicitly highlighted dose.
