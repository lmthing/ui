## Purpose

Follow a multi-week workout plan, track completion and start scheduled sessions.

## Pick

A multi-week workout program with week and day numbers, workout duration, rest days, and completion. Not one active strength session (Workout), repeated habits (HabitGrid), a course path (Path), or ungrouped tasks to tick off (Checklist).

## Writer

- Use Monday = day 1 through Sunday = day 7. Each week/day pair is unique and in the plan; set rest true only for rest days. Leave goto null unless a workout screen was supplied. Progress counts are derived.
- Use style "list" to show all weeks in sequence; otherwise leave style null. If asked to hide workout durations, keep minutes in the data and write detail brief.
