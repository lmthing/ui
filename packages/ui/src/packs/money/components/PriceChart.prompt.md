## Purpose

See how one holding's price moved over a chosen period.

## Pick

A holding's price history with selectable day, week, month, year and all ranges. Not a compact recent value trend (Sparkline), one sum (Amount), personal measurements (Measurements), or a business metric (LineChart).

## Writer

- points are 8–60 numeric prices in time order. Code derives current price and change; never write them or currency.
- To omit the change summary only: detail brief, emphasis null. Leave emphasis null unless explicitly requested.
