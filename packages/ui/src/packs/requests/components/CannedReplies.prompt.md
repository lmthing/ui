## Purpose

Find a saved reply and put it in a support draft without sending it.

## Pick

Filter and preview reusable support or repair reply templates, then insert one into the active draft without sending. Not typing a blank reply (Composer), browsing generic rows (List), or showing the request stream (RequestThread).

## Writer

- Every template category and activeCategory must match a declared category. Use null for an uncategorized template or to start on All. All is a built-in filter, not a category to write.
- For title chips with no initial snippets set detail to "brief" and keep every template body.
