# Requests copy

Data-only formatting and reading helpers use the Requests language dictionary. Import through `index.ts`.

- `RequestQueue.ts`: queue sorting, grouping, reading, and loading helpers.
- `RequestThread.ts`: thread ordering, timeline, reading, and loading helpers.
- `RequestTriage.ts`: triage reading helper.
- `SlaPolicy.ts`: deadline validation, clock projection and SLA reading.
