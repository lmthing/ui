## Purpose

Review and approve the hours each person worked during a week.

## Pick

Review and approve staff hours for seven days, or let an employee review their own daily clock punches before submitting. Not a chart of totals (Bars), a planned rota (Roster), or a generic table (Table).

## Writer

- Give seven daily hours, Monday first, using zero for days not worked. Do not write totals or overtime.
- When asked to hide the daily breakdown, write detail "brief" and still supply all seven hours. Use null for unrequested detail.
- Use style "mine" for an employee reviewing and submitting their own timesheet. Supply exactly one row and put their clock punches in punches using Monday 0 through Sunday 6, from and optional to; omit to if still open. Do not invent punches.
