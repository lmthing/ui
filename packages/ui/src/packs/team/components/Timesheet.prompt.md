## Purpose

Review and approve the hours each person worked during a week.

## Pick

Review each worker's actual hours for seven days and approve their weekly row. Not a chart of daily totals (Bars), a planned rota (Roster), or a generic table (Table).

## Writer

- Give seven daily hours, Monday first, using zero for days not worked. Do not write totals or overtime.
- When asked to hide the daily breakdown, write detail "brief" and still supply all seven hours. Use null for unrequested detail.
