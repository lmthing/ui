# Commerce copy

Pure helpers for localized commerce component copy. Import through `index.ts`.

- `ProductGrid.ts` formats current and previous product prices for the view and reading.
- `VariantPicker.ts`: visible price differences and per-option reading.
- `SizeGuide.ts`: measurement conversion, fit wording and size-chart reading.
- `SavedList.ts`: saved-price comparisons, stock and price-drop badges, and target price readings.
