# Commerce component tests

- `CartBar.test.ts`: basket summary schema, hidden state, rendering, reading, and navigation.
- `Checkout.test.ts`: schema, fallback, rendering, reading, and dispatch for checkout.
- `OrderStatus.test.ts`: fulfillment milestones, completion, and seller-only advancement.
- `ProductGrid.test.ts`: schema, fallback, rendering, reading, and dispatch for the product grid and menu.
- `OrderSummary.test.ts`: receipt boundaries, rendering, reading, and reorder dispatch.
- `Promo.test.ts`: schema, fallback, rendering, reading, and dispatch for offers and discount codes.
- `VariantPicker.test.ts`: schema, fallback, parts, variants and availability-gated selection.
