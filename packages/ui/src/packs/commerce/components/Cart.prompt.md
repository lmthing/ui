## Purpose

Review and edit what you are about to buy.

## Pick

One shopping basket before ordering, with editable quantities, removal, a promo code and computed totals. Not browsing several past orders (List), a receipt for one placed order (OrderSummary), or a grocery checklist (GroceryList).

## Writer

- Write each line's unit price and quantity. The optional delivery charge is separate; do not write subtotals, line totals or a grand total.
- Keep supplied variant names in the line data. If asked to hide only those notes, write exactly {"detail":"brief"} for the axes.
- For a generated image, use `product` or `dish` in `photo`. Use only for a representative image of a line item. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
