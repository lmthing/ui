## Purpose

Notice an offer, copy its discount code or open the offer.

## Pick

A shop discount or offer with optional copyable code, expiry and product photo. Not an urgent warning or service notice (Banner) or a headline fact (Hero).

## Writer

- To keep a saved photo but hide the thumbnail, write the reference in photo and set media to "none". In that case write {"emphasis":null} unless emphasis was separately requested.
- Use endsAt for the local closing time (HH:MM). For time remaining set style "countdown" and supply ends, the local closing date. If only a time is known, set endsAt and leave style null.
- For a generated image, use `cover` or `poster` or `product` in `photo`. Use only to illustrate the offer, not to show price or legal text. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
