## Purpose

Lock in the first player to buzz and show how much later others tapped.

## Pick

Arbitrate who buzzes first in an in-person quiz or reaction round on one phone. Not one elapsed time (Timer), ordered turns (TurnOrder), random picks (Spinner), or question display (Trivia).

## Writer

- Write the players, swatches, and an optional public prompt. Never write a winner, lock state, or timestamps.
- For stacked horizontal pads write {"arrange":"rows"}; the default grid spreads pads around the corners.
