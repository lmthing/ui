## Purpose

Draw one named option at random, with or without repeats.

## Pick

Pick one labelled option randomly. Not deliberate choices (Choice, Chips), numbered dice (Dice), balanced teams (TeamPicker), or votes (Poll).

## Writer

- Write 2–6 distinct option labels. Never write selected index, used options, remaining count or stored draws.
- To hide only the draw-pool legend write {"detail":"brief"}; keep every option label.
