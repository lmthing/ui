## Purpose

Track each player's live total and resource counters around a shared table.

## Pick

Live life or point totals and resource counters for multiple tabletop players. Not one isolated number (Counter), round history (ScoreSheet), or a sports match (Scoreboard).

## Writer

- Write starting totals and counter seeds, not net changes or match results.
- Use `arrange: "grid"` for two columns of player pads, or `"rows"` for one full-width pad per row. Use `style: "stack"` for a single-side view with every pad upright.
