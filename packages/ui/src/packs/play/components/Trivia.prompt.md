## Purpose

Host questions aloud, reveal answers and advance without grading submitted responses.

## Pick

Host-controlled question and answer reveals for players answering aloud or on paper. Not private option selection (Choice), graded submissions (Quiz), or spaced recall (Flashcard).

## Writer

- Write seed question, answer, optional explanation/photo, points and two to four display-only choices if requested. Keep the answer in answer; never write correct-choice indexes, submissions, grades, awarded scores, current index or reveal state.
- To hide photos alone use {"media":"none","emphasis":null}. Keep the supplied photo in the question data. Use hero only when the user separately asks for large question text.
- For a generated image, use `item` or `plant` or `pet` or `place` or `step_illustration` in `photo`. Use only if it helps interpret the question without revealing the answer. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
