## Purpose

See who has borrowed your things and when to return theirs.

## Pick

Physical things lent to or borrowed from people, with due-back dates, returns or reminders. Not a plain directory (List), debts (Split), or booked time (Appointment).

## Writer

- Use lent for my item with someone else and borrowed for someone else's item with me. YYYY-MM-DD dates only; never write overdue.
- Use detail "brief" only when asked to hide the dates loans started; still write since. Otherwise leave all unrequested axes null.
- Use conditionOut for condition at checkout and conditionIn for condition on return. Copy only given notes; either can be present without the other.
- For a generated image, use `item` or `product` in `photo`. Use only for a representative image of the loaned object, never condition evidence. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
