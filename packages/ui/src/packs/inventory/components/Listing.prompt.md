## Purpose

Review an offer to rent or buy real estate, then save it or contact the advertiser.

## Pick

A dwelling actually offered for rent or sale, with beds, baths, floor area or lease terms. For a single notice or any other photo-and-text preview that opens more, choose Card instead. Not a venue to visit (PlaceCard) or goods for sale (Product).

## Writer

- Price is a number without a currency, per is month/week for rent and none for sale. Area uses m2 or ft2; photos go in a separate Gallery.
- For an ordinary listing with a description, end with "detail":null. Keep the supplied about text.
- Only an explicit request to hide the description sets "detail":"brief"; keep about in the data.
