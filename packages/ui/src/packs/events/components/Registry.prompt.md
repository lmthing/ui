## Purpose

Share a gift list and keep guests from choosing the same gift.

## Pick

A shared event gift list with gift prices, where to buy, and who claimed a gift for hosts. Not a checklist for personal tasks (Checklist), shopping (ProductGrid) or a personal wishlist (Wishlist).

## Writer

- Only give by for an already claimed gift in the host view; omit it for guests. Prices are numbers.
- If explicitly asked for rows without photos, set lead to "none" and retain any supplied photo references.
- For a generated image, use `item` or `product` in `photo`. Use only for a representative image of a gift. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
