## Purpose

Find sessions across an event's tracks and bookmark a personal agenda.

## Pick

Multi-room or multi-stage sessions at one event, with track filters, capacity and personal bookmarks. Not a single-track day (Timeline), a holiday itinerary (Itinerary) or weekly classes (Timetable).

## Writer

- Give each session a distinct id and a track from tracks. Use HH:MM with end later than start. If supplied together, booked cannot exceed capacity. Do not write remaining capacity or conflicts.
- Use style "mine" for the bookmarked agenda. Use detail "brief" only to hide speaker names; keep writing any supplied speaker names. Leave detail null unless requested.
