## Purpose

Manage smart-home rules that run connected devices when their triggers occur.

## Pick

Automatic smart-home rules with trigger conditions, device actions, enable switches and manual runs. Not manual scenes (Devices), household chores (Chores, CareSchedule), or a repeat value in a form (Field).

## Writer

- If asked to hide device action summaries, set detail to "brief".
- Optional lastRun is an observed ISO timestamp with an offset, e.g. "2026-11-20T07:00:00+00:00"; omit it when unknown.
