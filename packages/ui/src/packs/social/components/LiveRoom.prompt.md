## Purpose

Join a live audio conversation, see who’s speaking, and ask to speak.

## Pick

Join or host a live multi-speaker audio room with an audience, a hand-raise queue, and stage controls. Not a recording (Player), a private call (ActiveCall), or asynchronous posts (Feed).

## Writer

- Use style "mini" only for a collapsed bar with the active speaker and Leave. Otherwise leave style null for the stage.
- Write detail "brief" when asked to hide the room topic and speaker role labels. Leave unrequested axes null.
