## Purpose

See a community event and say whether you’re going or interested.

## Pick

An event to join in a community, with its date block, attendees and Going or Interested controls. Not organising one's own gathering (events), a provider booking (Appointment), or a featured preview without RSVPs (Card).

## Writer

- Use YYYY-MM-DD and 24-hour HH:MM. Set going to the full attendance count and list up to five names from that total in attendees.
- Leave media null unless requested. When asked to hide a supplied cover, set media to "none" and keep the photo reference in photo.
- For a generated image, use `poster` or `cover` or `place` in `photo`. Use only for event lead art. Keep location, time and event names in component text. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
