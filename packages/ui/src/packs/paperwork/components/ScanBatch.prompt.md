## Purpose

Arrange scanned pages and save them as one local PDF.

## Pick

Stage multiple scanned pages, reorder or replace pages and assemble one local PDF. Not a single capture (Camera), browsing photos (Gallery), or opening a saved document (Documents).

## Writer

- Use only supplied opaque local:<id> or synthetic lib:<id> page references in scan order. Use an empty pages array to start scanning. Do not write page numbers or counts.
- Use style "review" for a single larger preview above the thumbnails. Use detail "brief" only when asked to hide page labels but keep the page numbers. Otherwise leave detail:null.
