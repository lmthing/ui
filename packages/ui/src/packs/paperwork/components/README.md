# Paperwork components

- `Documents`: private local document register.
- `Renewals`: administrative notice and renewal dates.
- `Receipts`: purchase evidence and reviewed allocations.
- `TaxYear`: linked filing-period evidence.
- `Signature`: private drawn marks on reviewed forms.
- `ScanBatch`: ordered scan staging and local PDF assembly.

The component door is generated by `pnpm build:entries`; the pack re-exports it.
