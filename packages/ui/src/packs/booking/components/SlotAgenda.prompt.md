## Purpose

Compare named sessions on one date and see which are available, full, or already booked.

## Pick

Named classes, sessions or staffing slots on one day, with time, capacity or booking state and optional assignee. Not interchangeable start times for one service (Slots), a conference agenda filtered by track (Sessions), or a simple list of names (List).

## Writer

- List separate sessions for one date in start-time order. Set status to "booked" only for the person's existing reservation, "full" when no places remain, and "available" otherwise.
- Include goto only for a distinct destination: available opens booking review, full may open a waitlist, and booked opens booking details. Omit it for read-only rows.
- Use detail "brief" only to hide secondary location and staffing information; retain those facts in the data.
- Include end only with a known end time after start, assignee only if known, and filled only when the capacity and actual number of places filled are both known. A staffing destination opens review, it does not silently assign.
