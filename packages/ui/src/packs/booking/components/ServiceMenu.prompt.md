## Purpose

Choose a bookable service by duration and price, grouped by offering.

## Pick

Services to book with numeric duration, price and optional group headings. Not plain things to browse (List), an existing booking (Appointment), or goods for sale (ProductGrid). Several ordinary things each with short details and their own link remain List.

## Writer

- A request to hide descriptions changes ONLY detail to "brief". Keep the supplied description in sub. Set lead, style and every row tone/mark to null unless separately asked; do not spell out defaults. An absent photo does not request lead "none".
- Set capacity only for an explicit group limit, deposit only for an upfront amount, and portfolio.goto only for a separate gallery screen. Keep the service's goto for booking.
- For a generated image, use `product` or `item` or `place` in `photo`. Use only when a representative picture helps tell a service apart. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
