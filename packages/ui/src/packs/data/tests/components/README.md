# Data component tests

- `ActivityLog.test.ts`: Audit entry schema, fallback, states, parts and record navigation.
- `Heatmap.test.ts`: Matrix bounds, static cell addresses, loading and numeric readings.
- `Table.test.ts`: Table schema, fallback, states, parts and read/act behavior.
- `LineChart.test.ts`: Line chart schema, fallback, states, parts and point selection.
- `Board.test.ts`: Stage and card bounds, parts, computed totals and moves with stable card ids.
- `BulkActions.test.ts`: Live Table selection, command parts and destructive confirmation.
- `Funnel.test.ts`: Stage bounds, fallback, conversion, state and drill-down.
