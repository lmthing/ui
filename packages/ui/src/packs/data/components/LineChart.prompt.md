## Purpose

Compare trends over time and inspect individual values.

## Pick

Compare one to three time series over four or more labelled points, with labelled axes and readable points. Not a tiny trend under one headline number (Sparkline), category amounts (Bars) or a holding's price (PriceChart).

## Writer

- Series values are numbers, one per label in the same order. Labels are at most six characters. Do not write axes, latest values, ticks or colours.
- If asked to omit the latest-value summary but keep the chart and point controls, use detail "brief"; otherwise leave detail null.
- Set goal to the requested numeric threshold. Set range only when a reporting period is specified; it describes all supplied points ("7d", "30d", "90d", or "1y").
