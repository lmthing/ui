## Purpose

Let group members claim or release a limited contribution place.

## Pick

A shared contribution sheet with counted places, claimants and claim/release for an ongoing group. Not a private task list (Checklist), bookable times (Slots), gifts (Registry) or staff cover (OpenShift).

## Writer

- Use unique snake_case slot ids. Claims must name an existing slot and be unique per member per slot; never exceed capacity. Do not write claimed or remaining counts.
- For summaries that expand to reveal claimants, write detail "brief" and keep the claims.
