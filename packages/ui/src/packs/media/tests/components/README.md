# Media component tests

- `Library.test.ts` covers the schema, fallback, parts, states, variants and read/act behavior.
- `Collection.test.ts` covers the schema, fallback, playlist summary, variants and play/follow controls.
- `Playlist.test.ts` covers the schema, fallback, playback rows, variants and download dispatch.
- `MiniPlayer.test.ts` covers host props, progress, finish variants and separate playback and navigation actions.
- `Highlights.test.ts` covers excerpt bounds, fallback, note visibility, address stability and source navigation.
- `ChapterList.test.ts` covers chapter bounds, timestamp rows, current marking and same-screen seeks.
- `Transcript.test.ts` covers line bounds, fallback, states, parts, playback following, seeking and saving lines.
- `AudioMatch.test.ts` covers track and history bounds, fallback and recognition controls.
