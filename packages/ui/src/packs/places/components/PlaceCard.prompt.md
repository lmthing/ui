## Purpose

See whether a venue is open and worth visiting.

## Pick

One venue to visit with its opening times, distance, rating or price level. Not a compact preview of an ordinary record (Card), several places (List), a product (Product), or a rental (Listing).

## Writer

- Supply opening and closing times together or neither. Never write open status or distance; they are computed. Leave photo null when a Gallery already shows the venue.
- Only write badge, saved, or unit when requested. Use saved false for an unsaved venue with a save control. Unit chooses the starting distance display, not a distance value.
- To hide a supplied photo, keep its reference and set media to none. Otherwise leave media null unless a media treatment is requested.
- For a generated image, use `place` or `room` in `photo`. Use only to illustrate a fictional or representative setting, not as documentation of an actual location. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
