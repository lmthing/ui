## Purpose

Plan recipes across the week's days and meals.

## Pick

A week matrix of recipes by day and meal, with empty cells to add meals. Not calendar marks (Calendar), staff shifts (Roster), or class periods (Timetable).

## Writer

- week is a real Monday date. List each meal column once. Every filled cell has one unique day/meal pair and its meal is a listed column. Empty add cells are computed, not written.
- Use media "none" only when asked for a text-only week or to hide recipe photos. Leave media null otherwise.
- Write kcal on individual recipes only when supplied, never daily totals. Use style "day" for a stacked agenda grouped by day.
- For a generated image, use `dish` in `photo`. Use only for a representative image of the meal. Keep any supplied reference. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
