## Purpose

Run several named cooking timers at once and adjust each independently.

## Pick

Two or more named cooking countdowns running independently, each with its own start, pause and add-a-minute controls. Not a single countdown (Timer) or a timed recipe instruction (CookSteps).

## Writer

- Write each timer's label and seed seconds, 1–14400. Never write remaining, finished, running, progress or sorted order; the device computes them.
- If asked to stack timers one per row instead of side by side, set arrange to "rows"; otherwise leave arrange null.
