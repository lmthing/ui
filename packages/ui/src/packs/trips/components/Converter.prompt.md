## Purpose

Convert between home and local currencies by entering either amount.

## Pick

Convert two editable amounts between home and destination currencies with a swap control. Not displaying one sum (Amount) or entering an expense (AmountPad).

## Writer

- Use value for the optional starting amount. Do not write currencies, the rate, or a date; the host supplies them.
- When asked to hide only the rate date, use detail brief. Do not fill in defaults for unrequested variants.
