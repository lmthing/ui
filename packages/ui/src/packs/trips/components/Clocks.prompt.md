## Purpose

Compare local time in several places with the time back home.

## Pick

Current local clock times in two to four named time zones, with offsets from home. Not elapsed or remaining time (Timer) or scheduled events (Timeline).

## Writer

- Use 2–4 labeled places and IANA time zone IDs such as Europe/London, America/New_York or Asia/Tokyo. The first place is home. Do not write times, differences or daylight flags.
- For one place per row, write "arrange":"rows". Otherwise leave arrange null unless a layout is requested.
