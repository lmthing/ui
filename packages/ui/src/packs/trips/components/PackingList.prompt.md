## Purpose

Pack by category or person, track quantities and see what remains.

## Pick

Items to put in luggage, grouped by category or traveller, with optional quantities and an overall packed share. Not everyday tasks (Checklist) or shopping for groceries (GroceryList).

## Writer

- Use 1–6 groups, each with 1–10 items. Write each packed flag; never write the packed share.
- When only asked to hide quantities, write "detail":"brief". Keep supplied qty values. Never write "full" for an unrequested axis; write null instead.
