# trips/copy

`Itinerary.ts` formats itinerary days, stops and travel durations.
`Clocks.ts` calculates and formats simultaneous local times, daylight and offsets from home.
- `Itinerary.ts`: formats itinerary days, stops and travel durations.
- `PackingList.ts`: packing progress, quantity formatting, and addressed reading.
- `index.ts`: pack copy exports.

Import through `index.ts`; built-in words live in `../lang`.
