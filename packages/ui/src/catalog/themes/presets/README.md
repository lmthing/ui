# catalog/themes/presets

One file per preset.

Built in step U1 (draft values), refined in U4. Read plan 4.3 first.

Files (exactly these, plus `index.ts` as the folder's door unless it is listed):

- `calm.ts` `minimal.ts` `warm.ts` `fresh.ts` `bold.ts` `playful.ts` `soft.ts` `editorial.ts` `paper.ts` `sport.ts` `night.ts` `mono.ts`
- `index.ts`

Rules:

- Shape of a file: plan 4.3 "Shapes" (`id`, `mood`, `font`, `numbers`, `shape`, `density`, `surface`, `roles.light`, `roles.dark`).
- Define all 12 colour roles for light and dark, except `accent`, `accentSoft`, `onAccent`.
- Mood, type and shape come from the preset table in plan 4.3. File name equals the preset id.
