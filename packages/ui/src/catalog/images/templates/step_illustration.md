# Prompt

Show the object and visible outcome of one task step. Prefer a clear object state over a person performing the action; show a hand only if indispensable to understanding the step.

No text, numerals, lettering, watermarks, logos or real brands. No real people or recognizable likenesses. No hands unless essential to the subject.

# Reject if

- Any text, logo, watermark, real brand, recognizable real person or unnecessary hand.
- The subject or requested art treatment is not recognizable.
- It implies a wrong or unsafe action, needs a caption to identify the step, or includes unnecessary hands or extra steps.
