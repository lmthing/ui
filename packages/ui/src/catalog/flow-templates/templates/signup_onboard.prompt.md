## Purpose

Create an account, complete essential setup, and reach a first useful task.

## Pick

Choose for creating a new account and helping the new member do a first task.

## Avoid

Not for signing in again, recovering access, or accepting an invitation to an existing space.

## Writer

- Show the reason for each requested input. Do not request secrets or real contact details in examples.
- Fill the member name slot with the person's display name. Put their sign-up email only in the account field.
- Keep verification distinct from first run. Optional preferences should never block the first useful task.
