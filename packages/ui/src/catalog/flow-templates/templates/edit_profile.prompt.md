## Purpose

Edit the profile people see without exposing private account details.

## Pick

Choose when someone wants to review, change and save their own public or team profile, with optional photo changes.

## Avoid

Not for viewing someone else's profile, changing login details, or adjusting an app preference.

## Writer

- Keep one identity through the current view, the edit form, and the saved profile. Name who can see each edited field.
- Keep changes in draft until Save. Allow retaking or removing a photo, and keep the existing photo if permission is denied.
