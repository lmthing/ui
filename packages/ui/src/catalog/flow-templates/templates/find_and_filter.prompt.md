## Purpose

Find a record in a browsable collection without losing search or filter context.

## Pick

Choose when someone searches or narrows a collection, opens a matching record, and returns to the same results.

## Avoid

Not for viewing one known record, using a search box by itself, or filtering slots to make a reservation.

## Writer

- Give results distinct names and at least two different short categories. Put one domain fact in each result so people can recognize it.
- Keep the query and selected filter visible when no results match. Clear both to restore the full collection, and return focus to the opened result on Back.
