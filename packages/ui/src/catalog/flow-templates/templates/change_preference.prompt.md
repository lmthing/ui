## Purpose

Review a setting, change its effective value, and verify or undo the saved choice.

## Pick

Choose for editing a discrete app preference such as digest frequency, units, or a default view.

## Avoid

Not for editing a public identity, reading notifications, setting up an account, or changing device permissions.

## Writer

- Name the existing value, each actual option, and what the values control. Back without Save must leave the active value alone.
- Show the saved value when reopened. A remote save error must preserve the old value and offer safe recovery.
