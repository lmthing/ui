# kit/base/input

Text controls, selections, sliders, scales and buttons. Depends only on text.

Files: `KitInput`, `KitTextArea`, `KitChip`, `KitOption`, `KitSlider`, `KitScaleTrack`, `KitAction`, tests, and `index.ts`.

Use this folder's `index.ts` door from other folders.
Names and props stay unchanged. Use catalog tokens and roles, never raw presentation values.
