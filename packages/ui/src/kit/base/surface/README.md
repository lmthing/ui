# kit/base/surface

Frames, rows, tiles, grids, strips and modal focus. Depends only on text.

Files: `KitCard`, `KitRow`, `KitBlock`, `KitTile`, `KitGrid`, `KitStrip`, `KitOverlay`, tests, and `index.ts`.

Use this folder's `index.ts` door from other folders.
Names and props stay unchanged. Use catalog tokens and roles, never raw presentation values.
