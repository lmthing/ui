# kit/base/matrix

Caller-built matrices and counted columns. Depends on text and surface through their doors.

`KitTable` pins headings on web and native, measures row heights across columns, and scrolls cells.
`KitWeekMatrix` composes it with exactly seven day headers and optional caller-built totals.
`KitColumns` draws counted panels in a sideways rail or vertical stack.
Loading projects caller text and child geometry into neutral shapes without mounting controls.
Empty drawings keep caller headings and counts; callers compose any empty-state message.
Targets dispatch through the shared controller; copy, ids and computed values belong to callers.

Use `index.ts` from other folders. Tests are adjacent; no catalog metadata lives here.
