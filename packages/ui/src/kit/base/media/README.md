# kit/base/media

Photos, playback, camera, maps, chat, stacks and tabs. Depends on text and input.

Files: `KitPhoto`, `KitMedia`, `KitCamera`, `KitAvatarStack`, `KitMapTile`, `KitRouteStop`, `KitBubble`, `KitSwipeStack`, `KitTabBar`, tests, and `index.ts`.

Use this folder's `index.ts` door from other folders.
Names and props stay unchanged. Use catalog tokens and roles, never raw presentation values.
