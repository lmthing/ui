# kit/base/data

Charts, progress and ranked markers. Depends only on text.

Files: `KitBars`, `KitSpark`, `KitRing`, `KitMeter`, `KitRank`, `KitShare`, `KitStepsTrack`, tests, and `index.ts`.

Use this folder's `index.ts` door from other folders.
Names and props stay unchanged. Use catalog tokens and roles, never raw presentation values.
