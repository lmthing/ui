## Purpose

Two to four shortcuts to different things the person can do next.

## Pick

Two to four separate navigation shortcuts together, such as logging, adding and viewing a schedule. Not independent jobs to tick off (Checklist), one main action (Button), or records to browse (List).

## Writer

- Each item is a peer link to a real screen, never a primary button, a status, or a pressed/selected choice. Name the destination ("Clients") or the task it opens ("Book walk"). Don't add a "Ready" or "Done" shortcut to show state. Use Button for the one main task and KeyValue for a record's status.
- Vertically stacked shortcuts set arrange to "rows" only. If no arrangement is requested, use null for arrange.
