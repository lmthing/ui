## Purpose

Find work waiting for a decision.

## Pick

Tasks by reference, status, owner, due time, priority and review action. Not browsing (List) or SLA inboxes (RequestQueue).

## Writer

- Preserve the record reference and keep status, priority and due time separate. Use "high" or "urgent" only when specified.
- Include both action and goto when the request names a button and destination, or neither for a read-only row. The action opens review and does not settle the work.
- Set detail "brief" only when asked to hide ownership. Keep the supplied owner in the data.
