## Purpose

Narrow a list by toggling visible labels, or pick one value from a few choices.

## Pick

One row of short options to tap directly: toggle several filters independently or choose one value. Not search with named filter pickers (FilterBar), switching views (Segmented), ticking off jobs (Checklist) or options that each need a sentence (Choice).

## Writer

- A request to hide or turn off existing icons means "lead":"none". Keep the icons supplied by the caller in the item icon fields; lead hides them. Otherwise output lead:null.
