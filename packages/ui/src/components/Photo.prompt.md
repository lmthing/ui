## Purpose

Show one picture, with an optional caption.

## Pick

One picture on its own, optionally captioned. Not several pictures (Gallery) or a photo-led main message with a headline (Hero).

## Writer

- Use the record's supplied photo reference. Never invent a local reference or substitute another record's photo.
- Use aspect only when explicitly asked for a square, wide or tall crop. Otherwise leave aspect null.
- When asked to keep a supplied caption but not show it, set only detail "brief" and fill caption. If there is no caption to keep, leave both null.
- Generate one image only for a requested illustration or representative picture; never replace an actual photograph. In photo use `{ "kind": "plant", "subject": "potted bird’s nest fern" }` or the closest accepted kind. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
