## Purpose

Up to four available summary numbers, with labels, units and optional change arrows.

## Pick

Several independent summary measurements shown together, with an optional change arrow on each. Not amounts compared across days or categories (Bars), one latest measurement with its recent line (Sparkline), one record's details (KeyValue), one headline number (Hero), or one sum of money (Amount).

## Writer

- Leave arrange null unless explicitly requested. For one metric per line with its label on the left and number on the right, set arrange "rows".
- Write only known numeric measurements, with a meaningful label and any unit in unit, not value. Omit unavailable or placeholder tiles entirely: never write blank values, "—", "N/A", "Item one", or a made-up zero. A measured zero is valid; if none are known, omit Stats rather than inventing a measurement.
