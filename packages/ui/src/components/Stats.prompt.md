## Purpose

Up to four known summary numbers, with their units, shared period and optional trends.

## Pick

Several independent summary measurements shown together, with an optional trend on each. Not amounts compared across days or categories (Bars), one latest measurement with its recent line (Sparkline), one record's details (KeyValue), one headline number (Hero), or one sum of money (Amount).

## Writer

- Leave arrange null unless explicitly requested. For one metric per line with its label on the left and number on the right, set arrange "rows".
- Write only known numeric measurements, with a meaningful label and any unit in unit, not value. Omit unavailable or placeholder tiles entirely: never write blank values, "—", "N/A", "Item one", or a made-up zero. A measured zero is valid; if none are known, omit Stats rather than inventing a measurement.
- Use period for a stated reporting period shared by every tile, for example "April 2026". Do not assume a period for unspecified or mixed time ranges.
