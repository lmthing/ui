## Purpose

One sum of money written properly, with its period, old price or change.

## Pick

One sum of money is the point: a balance, a price, a total or what is owed. Not several figures side by side (Stats), the screen's headline in words (Hero), or the price on each row of a list (List).

## Writer

- Use JSON null for every unrequested Amount axis, not its default string. Never write comfortable, normal, or card just because they are defaults.
- If asked only to hide the secondary note, use detail "brief" and keep sub; emphasis must be null.
- For one large focal figure, use emphasis hero. Use style total only for a total with the automatic label.
