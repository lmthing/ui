## Purpose

See how one measurement is changing, alongside its latest value.

## Pick

One latest value with its recent rise or fall. Not separate amounts per day or category to compare (Bars), or several summary numbers (Stats).

## Writer

- If asked only to hide the trend line: detail "brief", tone null; still store the series.
- If asked to warn about a series, use tone "warn" and keep detail. The line is normally visible; a warning, a latest value or a falling series never asks to hide it.
