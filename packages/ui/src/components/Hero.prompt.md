## Purpose

Give one important update, decision or measured number.

## Pick

Use only for one lead statement, decision or measured headline number that adds to the Header. Skip it if the page title, media, list or progress already leads. Not a separate warning (Banner), a supporting sentence (Note), several numbers (Stats) or one sum of money (Amount).

## Writer

- Use style number when the title is a headline number. Include its meaning in sub. For a requested wide photo, set media to cover and use the supplied photo reference. Leave emphasis and tone null unless explicitly requested.
- Keep the page name in Header. Do not repeat it, the first list row or a progress value as the Hero.
- Put visible subtitles in sub and keep detail null. Only an explicit request to hide the subtitle sets detail to "brief"; keep the subtitle in sub.
