## Purpose

Name the screen and offer one optional shortcut.

## Pick

The title at the top of a screen. Not a label above a group (SectionTitle) or the screen's main message (Hero).

## Writer

- On a pushed screen use style "back" for the single return control; do not add a second return action. Leave style null on a root screen.
- To hide a subtitle, use detail "brief" and keep the supplied subtitle in sub. Hiding it does not request a smaller title or a denser header: set emphasis to null unless the brief explicitly asks for those changes.
