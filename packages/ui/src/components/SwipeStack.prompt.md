## Purpose

Choose between things one at a time, swiping the current one to keep or skip.

## Pick

Decide which of several things to keep or skip, one at a time. Swipe only the top choice. Not browsing several captioned pictures together (Gallery) or opening a single featured preview (Card).

## Writer

- To hide only photos, write "media":"none" and "detail":null. Keep supplied descriptions in meta. Set "detail":"brief" only if asked to hide descriptions. Never write "detail":"full" to keep the default.
