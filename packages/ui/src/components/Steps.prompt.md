## Purpose

Know your current place in a short ordered flow.

## Pick

Show the current position in a short setup or booking flow. Not independent jobs to tick off (Checklist) or progress toward a numeric goal (Progress).

## Writer

- If asked to show only the step position without the task name, set detail to "brief". Otherwise leave detail null.
- Use a `step_illustration` slot in `photo` only when a picture clarifies the current step. Omit it in brief mode and never illustrate the whole sequence. In an image slot, use a short plain noun phrase from the app’s world for `subject`; no style, camera, palette or layout words.
