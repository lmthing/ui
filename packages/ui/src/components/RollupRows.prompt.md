## Purpose

Compare the same measured total and supporting figures across several entities without a wide table.

## Pick

Compare one like-for-like number per entity, with its unit and period and optional breakdown or linked detail. Not independent headline measurements (Stats) or the attributes of one record (KeyValue).

## Writer

- Every row compares the same metric, unit and period. Use numeric values without suffixes. Include total only if supplied and a destination only for a real detail link.
- A breakdown is short supporting text about contributions to one number. Leave detail null unless explicitly asked to hide breakdowns while keeping the data, then set detail "brief".
