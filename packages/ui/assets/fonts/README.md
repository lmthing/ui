# assets/fonts

OFL font files for the preset type families.

Built in step U2. Read plan 5.2 first.

Files (exactly these, plus `index.ts` as the folder's door unless it is listed):
- Inter (grotesk), Source Sans 3 (humanist), Nunito (rounded), Fraunces with Source Serif 4 (serif), Barlow Condensed (condensed numbers)

Rules:
- Only SIL Open Font Licence fonts. Record the licence next to each file.
- `kitFontAssets` maps family names to these files for the host's font loader. Swapping a family is one file.
- Families are proposals until the font question is settled.
