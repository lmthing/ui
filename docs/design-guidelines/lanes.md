# Expert lanes

Start with [P0 before P1 before P2](gap-matrix.md). These are future work assignments, not changes made by this synthesis. Each path below is relative to the UI worktree. Braces denote an explicit allowlist, not a wildcard. No lane edits another lane's files; write a finding against the owning base or renderer with observable behavior and evidence. The orchestrator owns shared generated entries, registries and app-layer/harness follow-ups. Add a new path to an allowlist before work starts.

## Core (three lanes)

Each core lane owns `packages/ui/src/components/{Id}.{tsx,test.ts,prompt.md}`, the corresponding `packages/ui/src/catalog/lang/en/{Id}.ts` when present, and `packages/ui/test/recordings/{Id}/**`, for **only** the IDs listed. Companion `<Id>.*.test.*` and `<Id>.*.tsx` files in the same folder stay with that ID. Shared language helpers, catalog docs and kit bases are not yours to change.

| Lane                                  | Owned IDs                                                                                                                                                                  | First fixes                                                                                                                                                                                   |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Core 1 · structure and content        | Article, Banner, Bubbles, Card, Empty, Gallery, Header, Hero, KeyValue, List, Note, People, Photo, Player, Profile, Review, SectionTitle, Steps, SwipeStack, TabBar        | List/KeyValue scannable full facts and conditional affordances; reason-specific empty; stable Back and long scope labels; poster-led Gallery vs operational rows.                             |
| Core 2 · data, spatial and signature  | Amount, Bars, Calendar, Canvas, Counter, MapPins, Progress, Route, Sparkline, Stats, Streak, Timeline, Timer                                                               | Period/units and aligned values; attach live/stale state to the same record; anchor the changed mark and exercise reduced-motion signature fallback. SwipeStack's view belongs to Core 1.     |
| Core 3 · input, action and commitment | Actions, Button, Camera, Checklist, Chips, Choice, Composer, Field, FileList, FilterBar, HandoffReceipt, PassCard, Scale, Search, Segmented, Sheet, SignInOptions, Success | Persistent field labels and units; no contradictory pending/sent/accepted; reachable action and proof of Back/confirmation; approval and HandoffReceipt use the same ID and real next action. |

## Packs (two lanes)

Each pack lane owns `packages/ui/src/packs/{pack}/**`, `packages/ui/test/recordings/pack/{pack}/**` and `docs/catalog/packs/{pack}.md` for the listed packs **except** `packages/ui/src/packs/{pack}/flow-templates/**`, which belongs to the new-components/templates lane. A reused core renderer remains Core-owned. File a request instead of changing it from a pack.
