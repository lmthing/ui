# Escape

- **Anatomy:** `Canvas` is a bounded composition with a named purpose, text equivalent and the smallest set of meaningful parts. Standard navigation, confirmation and input stay in kit controls.
- **States:** Check missing/invalid content, interrupted interaction and the accessible still fallback. If the custom drawing cannot be used, the job remains understandable.
- **Variants:** Use the declared drawing vocabulary, not a new free-form axis or theme overrides. Prefer a catalog component or a composition of catalog parts when a variant suffices.
- **Motion:** Static by default. If the surrounding task calls for an effect, use a shared kit transition and document the unchanged reduced result.
- **Do / don't:** Use for an otherwise unrepresentable schematic with a textual meaning; never use it to draw a custom button, work around tokens, or fake a new pack.
