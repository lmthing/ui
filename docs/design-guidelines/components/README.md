# Component families

The family follows the person's task, not the file's name. The catalog's [`meta.group`](../../catalog/core.md#4-the-full-core) describes the underlying renderer; beyond-phone and signature are also cross-cutting review families. Apply the [flow](../patterns-and-flows.md) and [motion](../motion.md) rules to pack components as well as core.

| Family                    | Use it for                                             |
| ------------------------- | ------------------------------------------------------ |
| [Structure](structure.md) | Header, SectionTitle, Steps, TabBar                    |
| [Content](content.md)     | Lists, editorial, media, identity and messages         |
| [Data](data.md)           | Measures, charts, temporal and spatial status          |
| [Input](input.md)         | Search, forms, selection and composition               |
| [Action](action.md)       | Commitments, confirmation and results                  |
| [Beyond phone](beyond.md) | Service, shared people, permissions and capture        |
| [Signature](signature.md) | A task-specific animation, not a new UI vocabulary     |
| [Escape](escape.md)       | Canvas only when named catalog parts cannot do the job |
