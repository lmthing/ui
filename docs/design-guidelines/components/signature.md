# Signature moments

- **Anatomy:** `SwipeStack`, `Streak`, `Route` and the other registered components have a stable object, a visible trigger, a single marked change and a lasting result label.
- **States:** Cover before, committed, cancelled or interrupted, and reduced motion. Zero progress and an unavailable route are not earned moments. Motion must not hide the focal object at entry.
- **Variants:** Choose an existing [eligible signature](../motion.md#signatures-and-contract) or none. Keep the same component parts and actions with different themes; match the signature to the main loop, not the fanciest preset.
- **Motion:** Follow the hand for a drag; settle or snap back on release/cancel and accept new input immediately. Time a milestone cue once after acceptance; use a still end-state in reduced motion. Keep normal navigation, waiting and errors quiet.
- **Do / don't:** Draw the just-completed delivery leg once; leave queued legs still. Never replay a flourish on every render, or hide a numeric result behind a counting sequence.
