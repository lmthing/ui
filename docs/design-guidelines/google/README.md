# Google Material Design 3

Research for the lmthing design expert, checked 2026-11-27. These are inputs to synthesis, not new catalog rules or a plan to clone Android. The reference phone is 390 logical units wide. Material dimensions are Android dp (type is sp); web examples use CSS pixels or scalable text units, not device pixels.

- [Foundations](foundations.md): adaptive layout, spacing, type, dynamic color, shape, elevation, icons and imagery.
- [Actions and navigation](actions-and-navigation.md): bars, rails, drawers, tabs, buttons, FABs, groups and tools.
- [Content and feedback](content-and-feedback.md): cards, lists, carousel, overlays, badges and progress.
- [Selection and input](selection-and-input.md): chips, controls, fields, pickers and search.
- [Material 3 Expressive](expressive.md): hierarchy, shape, emotion, and motion as part of the interaction.
- [Motion system](motion.md): springs, timing tokens, transition choices, choreography and testing.
- [Patterns and flows](patterns-and-flows.md): adaptive journeys, task entry, repair, commitment and handoff.
- [Accessibility](accessibility.md): targets, contrast, semantics, input, motion and verification.
- [Writing](writing.md): practical interface copy, localization and accessible labels.
- [Google Play Best of](play-best-of.md): 2026 and 2025 app case studies and what transfers.

**Read a component spec** for its anatomy and target sizes. **Read the motion page** for how it changes. **Read “For lmthing”** for the existing catalog fit and what still needs investigation. Google guidance, Android implementation defaults, and lmthing proposals are marked separately.
