# Apple Human Interface Guidelines research

Primary-source notes for the lmthing design-guidelines synthesis, November 2026. Apple guidance, web standards, and proposed lmthing defaults are labeled separately. The reference viewport is 390 logical units; CSS pixels, iOS points, and backing pixels are not interchangeable. These notes propose design and validation directions; they don't change the catalog contract.
