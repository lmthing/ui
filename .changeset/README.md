# changesets

Versions and changelogs.

Built in step U0. Read plan 4.11 and 10 first.

Files (exactly these, plus `index.ts` as the folder's door unless it is listed):
- Generated by `changeset init`, plus `config.json`

Rules:
- There is one version for `@lmthing/ui`. It is also the catalog version stamped on every saved spec.
- Patch: wording, examples, a loosened limit. Minor: a new component, style, optional prop, icon, layout, pack or `KitStyle` field. Major: removal, rename, tightened limit, changed meaning, which needs a migration.
