# apps/site/src

The landing site as a small React app (hash routes, code-split). `landing/` is the home page,
`playground/` the per-component page, `packs/` the pack pages, `create/`, `view/` and `tryit/` the LLM
demos, `live/` the only folder that loads the kit, `theme/` the three-enum theme, `data/` the generated data.
