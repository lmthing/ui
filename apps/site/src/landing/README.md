# src/landing

The home page, one file per section: `Hero`, `StatsStrip` (build-time counts), `IdeasSection`,
`LlmSection` (create, view and act demos), `TrySection` (a model in the visitor's browser), `PacksSection`
(waves and statuses), `ComponentIndex` (search with gallery screenshots), `ThemesSection` and its lazy
`ThemeShowcase`. Sections that draw live screens load them lazily.
